Hex Clock - Privacy Policy

Last updated: November 21, 2026

Data Collection

Hex Clock does not collect, store, track, or share any personal data.

The extension and website only uses your device's local time to display a clock and change the background color. Everything runs locally in your browser.

Third Parties

The Chrome extension uses the default Google Chrome web store analytics with Google Analytics anebled but no tracking, or advertising services.The website uses GoatCounter analytics.

Source Code

Hex Clock is open source. You can view the source code on GitHub.
